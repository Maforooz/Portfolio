Umbrella-Bus-Station

Tools: Arduino, LED Strips, Conductive Copper Tape, Laser Cutting

Type: Tangible Interaction / Physical Computing

The Umbrella Bus Station is a physical prototype of a smart, interactive bus stop designed for Vancouver's rainy and low-light environment. The station features an umbrella-shaped rooftop and an automatic lighting system that activates when a person walks inside, enhancing visibility and safety for both passengers and approaching bus drivers. Using Arduino, we connected 12V LED strips to a custom touch-sensor system made from conductive copper tape, which detected user presence at the station's entrance and exit. The lights turned on when someone entered, and automatically turned off once they left. We also laser-cut a clear, modular plastic structure to house the components and tested it in a physical environment.

Key Features:

  • Automatic Lighting: LED system activates when users enter the station
  • Touch-Sensor System: Uses conductive copper tape for presence detection
  • Modular Design: Laser-cut structure for easy assembly and maintenance
  • Weather Protection: Umbrella-shaped design for rain protection

Lesson Learned

This project taught me how to bring interactive ideas into the physical world. I learned how to work with hardware like Arduino and sensors, how to think through user behavior in real spaces, and how small details—like how lights respond—can shape a person's sense of safety and comfort. Collaborating with a teammate also helped me grow my problem-solving and communication skills throughout the process.

Smart-Armrest

Tools: Arduino, pressure sensor, portable speaker, circuit wiring

Type: Tangible Interaction

This project was designed to help nervous flyers manage anxiety during takeoff—a phase of flight known to spike stress levels. Using Arduino, we built a smart armrest that detects a passenger's tight grip through a pressure sensor. When the grip indicates rising anxiety, the system automatically plays calming music through a portable speaker. Originally envisioned as a multi-sensor wearable system, the final prototype was refined into a more practical and accessible solution using simple hardware components. The goal was to provide immediate comfort without needing user input, making air travel a bit more soothing for those who need it most.

Key Features:

  • Pressure Detection: Sensor detects user's grip intensity
  • Automatic Response: Triggers calming music when stress is detected
  • Non-Invasive Design: Integrated into standard airplane armrest
  • User-Friendly: Requires no manual input from the user

Lesson Learned

This project taught me how to simplify a complex idea into a working prototype using the tools available. I learned how to identify the core user need and focus on one key input—the tight grip—to design an effective, user-friendly solution. It also helped me improve my skills in using Arduino and thinking creatively about real-world applications of technology.
